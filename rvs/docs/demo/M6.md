# M6 demo note

> **Point-in-time snapshot.** Written when this milestone was finished: test counts, timings, caveats and command forms were true then and are not updated. For the current state see the user guide, `docs/DECISIONS.md`, `docs/DEVIATIONS.md` and `docs/RELEASE.md`.


```
rvs-studio                      # first run is guided; Ctrl+Shift+M switches to expert; F1 opens the guide
rvs init my-project --template satellite --git
rvs selftest [--manifest dist/rvs-studio]
sh scripts/build_release.sh     # guide, build, optional signing (RVS_SIGN_CMD), MANIFEST.sha256, archive
./install.sh                    # per user; ./uninstall.sh removes it, projects and settings stay
```
What works
- Guided wizard with live quality hints, field help, completion of IDs/values, glossary editor; expert mode with dense table, in-place edits (reason asked for baselined items), shortcuts for every action (`Ctrl+/` lists them), go to item, next/previous problem.
- New project from templates, example projects, recent projects, async open, crash reports without project content.
- Offline user guide (both walkthroughs, command reference, rules/finding codes, file format) checked against the code by tests.
- Install/uninstall scripts (Linux tested), manifest verification, signing hook.
- Performance at 5,000 items: cold open 6.0 s (accepted V14), warm 0.6 s, one edit 0.6-0.7 s.

Caveats
- Windows scripts and build untested (V22); no code-signing certificate configured; ReqIF deferred.
