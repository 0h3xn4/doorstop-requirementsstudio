# M0 demo note

- `pip install -e .` (runtime only) gives `rvs --version` and `rvs-studio` (empty Carbon-styled window: IBM Plex bundled, Problems dock, Help > About).
- `QT_QPA_PLATFORM=offscreen pytest` → 16 tests: layering rules, runtime-vs-dev dependency split, GUI smoke, CLI, and the offline test (sockets blocked, app still starts).
- `pyinstaller packaging/rvs.spec` → portable folder `dist/rvs-studio/` (~150 MB), starts without network (verified headless; Tk, doorstop server/GUI, Qt network/web excluded).
- `sh scripts/sbom.sh` → CycloneDX SBOM + licence report of the runtime install (19 packages; PySide6/Doorstop LGPL, rest permissive/MPL).
