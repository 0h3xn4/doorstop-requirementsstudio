# M2 demo note

> **Point-in-time snapshot.** Written when this milestone was finished: test counts, timings, caveats and command forms were true then and are not updated. For the current state see the user guide, `docs/DECISIONS.md`, `docs/DEVIATIONS.md` and `docs/RELEASE.md`.


```
rvs-studio                      # File > Open Project… -> examples/satellite300
rvs validate examples/satellite300     # exit 1 on purpose: 7 seeded defects
```
What works
- **Browse:** document tree (documents nested by parent, items under their document), item table with column chooser (View > Columns or right-click the header), sorting, filters (search, status, only-with-problems), and jump from tree/table/Problems panel to the editor.
- **Edit:** form generated from the document template (so free attributes appear automatically), Markdown statement with live preview, parent links, reason field. Save writes through Doorstop, appends who/when/why to `history/`, re-validates, and refreshes every view. A reason is required for baselined items. Unsaved changes block switching items (inline warning). Undefined acronyms are underlined in the statement.
- **Create:** Item > New Requirement… (document, title, parents) creates a draft with a template statement.
- **Quality rules (config/rules.yaml):** shall-present, single-statement, vague-words, no-implementation, verify-method-set, has-parent, verified-when-approved, undefined-acronym; each finding has a code `RVS-RULE-…`, plain-language message, how-to-fix hint and item jump. Also surfaced: Doorstop's suspect links and missing child links.
- **Offline, strictly:** no network-capable module is loaded in the process (offline test), per your instruction.

Tests: 131 (rules positive/negative, glossary, authoring/history, satellite300 defects, 25 pytest-qt GUI tests incl. create/edit/save, Problems jump, filters, columns).

Caveats
- Visual polish against Carbon is basic (form spacing, table density); M6.
- Every save re-validates the whole project; fine at 300 items, needs the M3 cache at 5,000.
- 340 "needs initial review" infos appear in satellite300; use "Errors only" or filter. A severity filter beyond errors comes with M3.
- Frozen (PyInstaller) build was launch-tested only, not driven.
- Verification-item creation and typed-link editing are M3; guided mode is M6.
