# M3 demo note

> **Point-in-time snapshot.** Written when this milestone was finished: test counts, timings, caveats and command forms were true then and are not updated. For the current state see the user guide, `docs/DECISIONS.md`, `docs/DEVIATIONS.md` and `docs/RELEASE.md`.


```
rvs-studio                                 # open examples/satellite300; tabs: Items | Traceability | VCM | Coverage | Graph
rvs export examples/satellite300 --vcm --only-gaps
rvs export examples/minimal10 --trace SYS:EPS          # childless items flagged
rvs export examples/minimal10 --impact SYS-0002 --format json
```
What works
- **Typed links** (satisfies, verifies, refines, conflicts-with) edited in the form (comma-separated IDs) and stored as extended attributes; validated for existing targets, self links, document kinds/direction, and verifies method consistency. Config in `config/links.yaml`. Suspect links (parent fingerprint changed) are listed in Problems and can be cleared on the item ("Clear suspect links", recorded in the history).
- **Traceability matrix** for any two documents, both directions; gaps highlighted (childless, orphan, unverified, unverified-approved).
- **VCM**: every requirement with method, level, verifying items, aggregated status and evidence; filters (document, method, level, status, only unverified); export to CSV; provenance block and a visible note that the ECSS layout is still a placeholder.
- **Impact** dock (tree and list) follows the selection; double-click opens an item. **Graph** tab: neighbourhood at depth 1-4, upstream above, downstream below, click a node to open it.
- **Coverage** per document: counts and percentages per status and per verification state.
- **New Verification Item** (Item menu): creates a planned, derived item that verifies the chosen requirements.
- **CLI**: `rvs export` (CSV/JSON) and `rvs validate --fast`.

Performance (5,000 items, 4 cores): warm open + all RVS checks 0.42 s; graph + VCM + trace + coverage 0.04 s; **cold open 6.0 s (target 3 s; accepted by the user, V14/D46)**. Full Doorstop validation still takes about 15 s, so the GUI runs it only on request.

Tests: 209 (+3 perf tests). New: link graph/validation, matrices, impact/coverage/neighbourhood, cache (never serves stale data), CLI export, graph layout, 16 GUI tests.

Caveats
- The GUI loads synchronously; a 5,000-item cold open blocks the window for about 6 s (background loading is M6).
- Matrices export to CSV/JSON only; XLSX/DOCX/PDF/HTML are M4.
- Verification-status aggregation (D38) and the VCM layout are tool conventions, not ECSS.
