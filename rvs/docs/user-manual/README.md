# User manual

This is the task-by-task manual for Requirements & Verification Studio (RVS): each page answers one question of the form "How do I ...?". It is short on purpose; the full reference (every field, rule and finding code) is the [user guide](../guide/01-getting-started.md), which also opens inside the application with **F1**.

New to RVS? Do [Getting started](../getting-started.md) first.

| I want to ... | Page |
|---|---|
| Start a project (from a template, or open an example) | [Create or open a project](01-create-a-project.md) |
| Write, edit, search and review requirements | [Write and edit requirements](02-write-and-edit-requirements.md) |
| Link requirements, see what depends on what, find gaps | [Link and trace](03-link-and-trace.md) |
| Find out what is wrong and how to fix it | [Check quality](04-check-quality.md) |
| Show that each requirement is met | [Verification](05-verification.md) |
| Record why things changed and freeze an agreed state | [Change control](06-change-control.md) |
| Get reports out, or change many items in a spreadsheet | [Import, export and reports](07-import-export-reports.md) |
| Script it, or run it in a build pipeline | [The command line](08-command-line.md) |
| Switch modes and themes, change shortcuts, find settings | [Modes, themes, shortcuts, settings](09-settings-modes-shortcuts.md) |
| Understand the files in a project folder | [Project files](10-project-files.md) |

Words you do not know are in the [glossary](../glossary.md).
