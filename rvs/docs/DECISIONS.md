| D38 | Verification status of a requirement = `aggregate_status` of the items verifying it: failed if any failed; passed/waived/planned if all are; none -> "not verified"; any other mixture -> "in-progress". | D39 | Traceability matrix relation = any link between the two documents (parent, satisfies, refines, verifies), direct only. | D40 | Impact = items that point at the changed item through parent, satisfies, refines or verifies links, transitively, each listed once at its shallowest depth; conflicts-with neighbours are listed separately as "related" | Downstream = depends on the item | D |

| D50 | Item tables: machine column names (`id, document, level, normative, derived, active, header, ref, text, parents`, then every template attribute). | D52 | `ExportRequest` + `build_output` (`exporters/export_request.py`) are the single description of an export; the CLI (`rvs export`) and the GUI export dialog both use it. Spec documents (`--spec`) are DOCX/PDF/HTML only; the items table is CSV/XLSX only | One code path | D |
